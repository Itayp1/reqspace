# S1 — ליבת השרת

[← חזרה לתוכנית](../../plan.md)

## מטרה
תוכנה שרצה במחשב Windows, יודעת אילו קבצי וידאו יש בתיקיות שהוגדרו, ומשדרת אותם לטלוויזיה ברשת הביתית.

## מה כלול
1. **קריאת הגדרות** מקובץ `config.json`.
2. **סריקת ספרייה** — מעבר על כל התיקיות ואיסוף קבצי וידאו.
3. **שידור וידאו** עם תמיכה בקפיצה בתוך הקובץ.
4. **כתוביות** — איתור קובץ כתוביות והמרת קידוד לעברית תקינה.
5. **גילוי אוטומטי ברשת** — הטלוויזיה מוצאת את המחשב בלי להקליד כתובת.
6. **דף סטטוס בדפדפן** — לבדיקה מהמחשב או מהטלפון.
7. **לוג** — הודעות ברורות בחלון השרת.

## פירוט

### 1. הגדרות (`config.json`)
```json
{
  "name": "המחשב בסלון",
  "port": 8765,
  "movies": ["D:\\Movies"],
  "series": ["D:\\Series"],
  "tmdbApiKey": "",
  "language": "he-IL"
}
```
- `movies` / `series` — רשימות נפרדות, כדי שלא נצטרך לנחש אם קובץ הוא סרט או פרק.
- אם הקובץ חסר או שגוי — הודעת שגיאה ברורה בעברית ובאנגלית, והשרת לא עולה.
- תיקייה שלא קיימת — אזהרה, אבל השרת ממשיך עם השאר (למשל כונן חיצוני מנותק).

### 2. סריקת ספרייה
- סיומות נתמכות: `mp4, m4v, mkv, webm, mov, avi, ts, m2ts`.
- מתעלמים מ: קבצים מוסתרים, תיקיות `Sample`/`Extras`/`Featurettes`, קבצים קטנים מ-50MB בתיקיית סרטים (דוגמיות).
- לכל פריט נשמרים: נתיב, גודל, תאריך שינוי (= "נוסף בתאריך"), כתוביות שנמצאו.
- **מזהה יציב לכל פריט:** hash של הנתיב היחסי לתיקיית השורש. כך הזיהוי לא משתנה בין הפעלות, וגם לא אם מעבירים את כל הספרייה לכונן אחר.
- **מתי סורקים:** בהפעלה, כל 10 דקות ברקע, ולפי בקשה (כפתור "רענן" באפליקציה).
- התוצאה נשמרת ב-`data\library.json` כדי שהשרת יעלה מהר גם עם אלפי קבצים.
- סריקה מעודכנת שומרת על מטא-דאטה שכבר הורד (לא מורידים מחדש מ-TMDB).

### 3. שידור וידאו
- בקשת `GET /stream/{id}` מחזירה את הקובץ.
- תמיכה ב-**HTTP Range** (תשובה 206) — הכרחי כדי שהנגן יוכל לקפוץ קדימה/אחורה ולהמשיך מאמצע.
- `Content-Type` לפי סוג הקובץ.
- קריאה בזרם (stream) — לא טוענים את הקובץ לזיכרון.
- סגירת הקובץ כשהטלוויזיה מתנתקת.
- **אין המרה (transcoding)** — הקובץ נשלח כמו שהוא.

### 4. כתוביות
- **איתור:** קבצים עם אותו שם בסיס כמו הווידאו, למשל:
  - `Movie.2010.srt`
  - `Movie.2010.he.srt`, `Movie.2010.heb.srt`, `Movie.2010.hebrew.srt`
  - תיקיית `Subs\` ליד הקובץ
- **עדיפות:** עברית ← ללא שפה מסומנת ← אנגלית. כל הכתוביות שנמצאו מוחזרות לאפליקציה (אפשר להחליף בנגן).
- **קידוד:** קבצי עברית ישנים שמורים לרוב ב-Windows-1255. השרת בודק אם הקובץ תקין ב-UTF-8; אם לא — ממיר מ-Windows-1255. מסירים BOM.
- **פורמטים:** SRT ו-VTT (הנגן תומך בשניהם). פורמטים אחרים (ASS/SUB) — לא בשלב זה.
- כתוביות שמוטמעות בתוך קובץ MKV — הנגן קורא אותן ישירות, השרת לא צריך לטפל.

### 5. גילוי אוטומטי ברשת
- השרת מאזין ל-UDP בפורט 8766.
- האפליקציה שולחת הודעת broadcast `TVMOVIES_DISCOVER`.
- השרת עונה: `{ "app": "tv-movies", "name": "המחשב בסלון", "port": 8765, "version": 1 }`.
- אם הפורט תפוס או חסום — אזהרה, והשרת ממשיך לעבוד (אפשר להקליד כתובת ידנית).

### 6. דף סטטוס (`http://localhost:8765`)
- שם השרת, כתובות IP לחיבור מהטלוויזיה.
- מספר סרטים / סדרות / פרקים.
- סטטוס סריקה ו-TMDB.
- רשימת קבצים "בעייתיים" (למשל AVI, או סרט ש-TMDB לא זיהה).

### 7. לוג
- בהפעלה: שם, תיקיות, מספר פריטים, כתובות לחיבור.
- בזמן ריצה: התחלת צפייה, שגיאות. בלי הצפה.
- נשמר גם לקובץ `data\server.log` (מתגלגל, עד 5MB).

## מבנה קבצים מתוכנן
```
server\
  server.js            נקודת כניסה
  src\config.js        קריאת הגדרות
  src\scanner.js       סריקת ספרייה
  src\stream.js        שידור + Range
  src\subtitles.js     איתור והמרת כתוביות
  src\discovery.js     UDP
  src\http.js          ניתוב בקשות
  data\                נוצר אוטומטית (לא בגיט)
```

## קריטריוני סיום
- [ ] השרת עולה עם `config.json` ומציג כתובות לחיבור.
- [ ] `GET /stream/{id}` עם `Range` מחזיר 206 עם הבייטים הנכונים.
- [ ] קובץ SRT בקידוד Windows-1255 מוחזר כעברית תקינה ב-UTF-8.
- [ ] הודעת UDP מקבלת תשובה.
- [ ] סריקה של 2,000 קבצים לוקחת פחות מ-10 שניות; הפעלה חוזרת מהירה (מטמון).
- [ ] ניגון הקובץ בדפדפן מתוך דף הסטטוס עובד, כולל קפיצה.
