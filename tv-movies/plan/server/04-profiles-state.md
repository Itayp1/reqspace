# S4 — פרופילים וסטטוס צפייה

[← חזרה לתוכנית](../../plan.md)

## מטרה
לכל אחד בבית פרופיל משלו, עם רשימה נפרדת של מה ראה, איפה עצר, ומה הפרק הבא שלו.

## פרופיל
```json
{ "id": "p1", "name": "איתי", "color": "#E53935", "avatar": "lion", "createdAt": 1791626461000 }
```
- שם, צבע ואייקון מתוך רשימה קבועה (בלי העלאת תמונות).
- **בהפעלה הראשונה** נוצר פרופיל אחד ברירת מחדל ("ראשי").
- יצירה, עריכה ומחיקה — מהאפליקציה (ראו [A2](../app/02-profiles.md)).
- מחיקת פרופיל מוחקת את הסטטוס שלו (אחרי אישור).
- **בלי סיסמאות / PIN** בשלב זה. נעילת פרופיל ילדים — רעיון עתידי.

## סטטוס צפייה (לכל פרופיל ולכל פריט)
```json
{
  "p1": {
    "<itemId>": {
      "position": 1534000,
      "duration": 7920000,
      "watched": false,
      "watchedAt": null,
      "playCount": 0,
      "updatedAt": 1791626464361
    }
  }
}
```
- "פריט" = סרט או פרק.
- זמנים במילישניות.

## כללים
| מצב | כלל |
|---|---|
| התחיל לצפות | נשמר מיקום רק אחרי 60 שניות צפייה (פחות = "רק הצצתי") |
| עדכון מיקום | האפליקציה שולחת כל 15 שניות, וביציאה מהנגן |
| סיים לצפות | מעבר ל-92% מהאורך, או 5 דקות לפני הסוף (המוקדם מביניהם) ← `watched=true`, מיקום מתאפס, `playCount+1` |
| סימון ידני "נצפה" | `watched=true`, מיקום מתאפס |
| סימון ידני "לא נצפה" | `watched=false`, מיקום מתאפס |
| צפייה חוזרת בסרט שנצפה | נשאר "נצפה"; המיקום החדש נשמר לצורך "המשך" |
| "המשך צפייה" | פריטים עם מיקום > 0 שלא הסתיימו, ממוינים לפי `updatedAt`. פריטים שלא נגעו בהם 90 יום יורדים מהשורה |

## שמירה
- הקובץ `data\state.json` (ופרופילים ב-`data\profiles.json`).
- כתיבה **אטומית**: כותבים לקובץ זמני ואז מחליפים — כדי שהפסקת חשמל לא תשחית את הקובץ.
- כתיבה מרוכזת (debounce של חצי שנייה).
- **גיבוי יומי:** `data\backup\state-YYYY-MM-DD.json`, נשמרים 14 אחרונים.
- המפתח הוא מזהה הפריט (hash של הנתיב היחסי) ← שינוי שם קובץ = פריט חדש. לכן בסריקה, אם קובץ "נעלם" וקובץ באותו גודל בדיוק "הופיע" — מעבירים אליו את הסטטוס.

## ייבוא / ייצוא
- בדף הסטטוס: הורדת `state.json` וטעינה בחזרה — לגיבוי ידני או מעבר מחשב.
