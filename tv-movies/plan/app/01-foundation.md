# A1 — בסיס האפליקציה: פרויקט, עיצוב, ניווט בשלט, חיבור למחשב

[← חזרה לתוכנית](../../plan.md)

## מטרה
שלד של אפליקציית Android TV שכל שאר המסכים נבנים עליו: מבנה פרויקט, עיצוב אחיד, ניווט עם השלט, ותקשורת עם השרת.

## טכנולוגיות
| תחום | בחירה | למה |
|---|---|---|
| שפה | Kotlin | הסטנדרט באנדרואיד |
| ממשק | Jetpack Compose + `androidx.tv:tv-material` | רכיבים שמותאמים לשלט (פוקוס, הגדלה, הדגשה) |
| נגן | Media3 / ExoPlayer | הנגן הרשמי של גוגל; MKV, כתוביות, קפיצה |
| תמונות | Coil | טעינה ומטמון של פוסטרים |
| רשת | `HttpURLConnection` + `org.json` (או Retrofit + kotlinx.serialization) | פשוט; ההחלטה בתחילת הפיתוח |
| ניווט בין מסכים | Navigation Compose | כפתור "חזרה" עובד נכון |
| ארכיטקטורה | ViewModel לכל מסך + Repository אחד לשרת | הפרדה בין מסך ללוגיקה |
| גרסת אנדרואיד מינימלית | Android 6 (API 23) | מכסה כמעט כל טלוויזיה |

## עיצוב
- **רקע כהה** (כמעט שחור), טקסט לבן, צבע הדגשה אדום.
- **עברית ו-RTL** בכל המסכים. שמות סרטים באנגלית מוצגים נכון בתוך ממשק עברי.
- **"מרחק 3 מטר":** טקסט גדול, כפתורים גדולים, שוליים של 48dp מקצוות המסך (overscan).
- **פוקוס תמיד ברור:** הפריט המסומן גדל קצת ומקבל מסגרת לבנה.
- שלד טעינה (skeleton) במקום ספינר במסכים עם שורות.

## ניווט בשלט
- חיצים — מעבר בין פריטים; OK — בחירה; Back — חזרה.
- **לחיצה ארוכה על OK** — תפריט מהיר (סמן כנצפה וכו').
- כפתורי מדיה (Play/Pause) עובדים גם מחוץ לנגן ← מתחילים לנגן את הפריט המסומן.
- **פוקוס נשמר:** כשחוזרים ממסך, הפוקוס חוזר לפריט שהיה מסומן ולמיקום הגלילה.
- Back במסך הבית ← יציאה מהאפליקציה (בלי "בטוח?").

## מסך חיבור למחשב (בהפעלה הראשונה)
1. "מחפש את המחשב ברשת…" — שליחת UDP broadcast (ראו [S1](../server/01-core.md#5-גילוי-אוטומטי-ברשת)).
2. נמצא מחשב אחד ← חיבור אוטומטי. נמצאו כמה ← בחירה מרשימה.
3. לא נמצא ← הסבר קצר + שדה להקלדת כתובת (`192.168.1.10` — הפורט מתווסף לבד) + "חפש שוב".
4. בדיקת חיבור עם `GET /api/info` ושמירת הכתובת.

## בכל פתיחה
- ניסיון חיבור לכתובת השמורה.
- נכשל ← חיפוש אוטומטי ברשת (אולי הכתובת השתנתה) ← אם נמצא מחשב **עם אותו שם**, מתעדכנים בשקט.
- עדיין נכשל ← מסך "המחשב לא זמין" עם: נסה שוב, חפש מחשב אחר, והסבר ("ודא שהמחשב דלוק והשרת פועל").

## הגדרות (מסך קטן)
- מחשב מחובר / החלפת מחשב.
- גודל כתוביות (קטן / בינוני / גדול).
- הפעלה אוטומטית של הפרק הבא (כן / לא).
- אודות: גרסה, קרדיט ל-TMDB.

## הרשאות ומניפסט
- `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_MULTICAST_STATE` (לגילוי במכשירים מסוימים).
- תעבורת HTTP לא מוצפנת מותרת (השרת ברשת הביתית).
- `LEANBACK_LAUNCHER` + באנר 320×180 ← האפליקציה מופיעה במסך הבית של הטלוויזיה.
- לא נדרש מסך מגע.

- [ ] כל הניווט אפשרי עם השלט בלבד; אין "מלכודות פוקוס".
