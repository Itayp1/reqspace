- השורות מגיעות מהשרת (`GET /api/home`, ראו [S5](../server/05-api.md)).
- גלילה אנכית בין שורות, אופקית בתוך שורה.
- **פריט Featured** מתעדכן לפי הפריט המסומן? — **לא**, נשאר קבוע (פשוט יותר ופחות עמוס). החלטה שאפשר לשנות.

### כרטיס פוסטר
- פוסטר ביחס 2:3.
- **✓ ירוק** בפינה = נצפה. **פס אדום** בתחתית = התקדמות.
- תווית "חדש" / "פרק חדש".
- בפוקוס: הגדלה קלה + שם מתחת.
- **OK** ← עמוד הסרט/סדרה. **לחיצה ארוכה** ← תפריט מהיר: נגן / סמן כנצפה / סמן כלא נצפה / הסר מ"המשך צפייה".
- **כפתור Play בשלט** על כרטיס ← ניגון מיידי (ממשיך מאיפה שעצר).

### עדכון
- רענון בכל חזרה מהנגן (ההתקדמות משתנה).
- כפתור "רענן" בהגדרות ← סריקה מחדש בשרת.

## מסך "סרטים" / "סדרות" (רשימה מלאה)
- רשת פוסטרים (6 בשורה).
- **סינון:** הכל / לא נצפו / נצפו / ז'אנר.
- **מיון:** שם / נוסף לאחרונה / שנה / דירוג.
- הסינון והמיון נשמרים לכל פרופיל (באפליקציה).
- קפיצה מהירה לפי אות: לחיצה ארוכה על ימינה/שמאלה ← גלילה מהירה.

## עמוד סרט
```
┌──────────────────────────────────────────────────────────────┐
│ ███████████ תמונת רקע (כהה) ███████████                       │
│  ┌────────┐   המטריקס                                         │
│  │ פוסטר  │   The Matrix · 1999 · 2:16 · ★ 8.2                │
│  │        │   אקשן · מדע בדיוני                               │
│  │        │   תקציר מלא…                                      │
│  └────────┘                                                  │
│              ✓ צפית ב-12.3.2026  /  עצרת ב-1:12:05             │
│              [▶ המשך]  [↺ מההתחלה]  [✓ סמן כנצפה]  [CC עברית]  │
│              1080p · MKV · כתוביות: עברית, אנגלית              │
└──────────────────────────────────────────────────────────────┘
```
- הכפתור הראשון בפוקוס: "המשך" אם יש התקדמות, אחרת "נגן".
- "כתוביות" ← בחירת כתוביות מראש (עברית / אנגלית / ללא) — נזכר לפרופיל.
- אזהרה עדינה אם הקובץ בפורמט שעלול לא להתנגן (`playable: "maybe"`).

## קריטריוני סיום
- [ ] מסך הבית נטען תוך פחות מ-2 שניות עם 1,000 פריטים.
- [ ] הפוקוס והגלילה נשמרים בחזרה מעמוד סרט ומהנגן.
- [ ] כל הפעולות (נגן, המשך, סימון) עובדות ומתעדכנות מיד במסך.
- [ ] תצוגה נכונה בלי מטא-דאטה (שם מהקובץ + פוסטר גנרי).
