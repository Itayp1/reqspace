# A4 — עמוד סדרה: עונות ופרקים

[← חזרה לתוכנית](../../plan.md)

## מטרה
לנווט בנוחות בסדרה, לראות מה נצפה, ולהמשיך בדיוק מהפרק הנכון.

## המסך
```
┌──────────────────────────────────────────────────────────────┐
│ ███████ תמונת רקע ███████                                     │
│ חברים  · 1994 · 10 עונות · ★ 8.9                              │
│ תקציר…                                                        │
│ [▶ המשך: עונה 2 פרק 4]  [✓ סמן סדרה כנצפתה]                    │
├───────────────┬──────────────────────────────────────────────┤
│ עונה 1  ✓     │ ┌──────┐ 4. הפרק עם הקוף           22 דק'      │
│ עונה 2  ◐     │ │ תמונה│ תקציר הפרק בשורה אחת…                  │
│ עונה 3        │ └──────┘ ▓▓▓▓░░░░                             │
│ Specials      │ ┌──────┐ 5. …                         ✓        │
│               │ …                                            │
└───────────────┴──────────────────────────────────────────────┘
```
- **עמודת עונות** (בצד ימין, RTL): ✓ = כל העונה נצפתה; ◐ = חלקית.
- **רשימת פרקים**: מספר, שם, תמונה, אורך, תקציר קצר, ✓ / פס התקדמות.
- בכניסה: העונה והפרק של **"הפרק הבא"** כבר מסומנים ובפוקוס.
- בלי מטא-דאטה: "פרק 4" + שם הקובץ.

## פעולות
| איפה | פעולה |
|---|---|
| כפתור עליון | ▶ המשך / התחל מעונה 1 פרק 1 |
| OK על פרק | ניגון (ממשיך אם יש התקדמות) |
| לחיצה ארוכה על פרק | סמן כנצפה / לא נצפה / **סמן עד כאן** / נגן מההתחלה |
| לחיצה ארוכה על עונה | סמן עונה כנצפתה / לא נצפתה |
| כפתור עליון | סמן סדרה כנצפתה |

## ניגון ברצף
- בסוף פרק ← מסך "הפרק הבא מתחיל בעוד 10…" ([A6](06-player.md#פרק-הבא)).
- אפשר לכבות בהגדרות.

## קריטריוני סיום
- [ ] הפוקוס נפתח על הפרק הבא הנכון.
- [ ] סימון עונה או סדרה מתעדכן מיד בכל הרשימה.
- [ ] סדרה עם 10 עונות ו-200+ פרקים נגללת בלי גמגום.
