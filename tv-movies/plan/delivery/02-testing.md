# R2 — תוכנית בדיקות

[← חזרה לתוכנית](../../plan.md)

## בדיקות אוטומטיות — שרת
| תחום | מה בודקים |
|---|---|
| ניקוי שמות | 30+ דוגמאות אמיתיות של שמות קבצים ← שם ושנה נכונים |
| זיהוי פרקים | `S01E02`, `1x02`, פרק כפול, Specials, קבצים לא מזוהים |
| Range | התחלה, אמצע, סוף, טווח לא חוקי (416), `HEAD` |
| כתוביות | UTF-8, UTF-8 עם BOM, Windows-1255 |
| סטטוס | כללי "נצפה", "הפרק הבא", שני פרופילים, כתיבה אטומית |
| API | כל נקודת קצה ב-[S5](../server/05-api.md): תשובה תקינה ושגיאות |
| TMDB | עם תשובות מוקלטות (בלי פנייה אמיתית לאינטרנט בבדיקות) |

הרצה: `npm test` בתיקיית השרת + ב-GitHub Actions.

## בדיקות אוטומטיות — אפליקציה
- בדיקות יחידה ל-ViewModels ול-Repository (עם שרת מדומה).
- בדיקת ממשק בסיסית (Compose UI test) לניווט בחיצים: בית ← סרט ← חזרה, הפוקוס חוזר למקום.
- הבנייה ב-CI חייבת לעבור לפני כל מיזוג.

## בדיקה ידנית בבית (לפני כל גרסה)
### הכנה
ספריית בדיקה עם:
- 5 סרטים: MP4 (H.264), MKV (H.265 + AC3), MKV עם כתוביות מוטמעות, AVI ישן, קובץ 4K גדול.
- 2 סדרות: אחת מסודרת היטב, אחת עם שמות "מבולגנים".
- כתוביות: UTF-8, Windows-1255, ללא כתוביות.

### תרחישים
- [ ] התקנה מאפס: מחשב ← שרת ← טלוויזיה ← גילוי אוטומטי.
- [ ] יצירת 2 פרופילים; צפייה בסרט בכל אחד; ה"המשך צפייה" נפרד.
- [ ] צפייה 5 דקות ← יציאה ← "המשך" חוזר לאותו מקום.
- [ ] צפייה עד הסוף ← מסומן נצפה, נעלם מ"המשך צפייה".
- [ ] סדרה: פרק ← פרק הבא אוטומטי ← מעבר עונה.
- [ ] "סמן עד כאן" באמצע סדרה.
- [ ] חיפוש בעברית ובאנגלית.
- [ ] כיבוי השרת באמצע צפייה ← הודעה ברורה ← הדלקה ← המשך.
- [ ] הפעלה מחדש של המחשב ← השרת עולה לבד.
- [ ] כל הניווט עם השלט בלבד, בלי פוקוס "תקוע".
- [ ] קובץ AVI ← הודעת שגיאה ברורה ולא קריסה.
