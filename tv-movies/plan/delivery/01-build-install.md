# R1 — בניית APK והתקנה בטלוויזיה

[← חזרה לתוכנית](../../plan.md)

## מטרה
דרך פשוטה לקבל קובץ התקנה (APK) ולהתקין אותו בטלוויזיה, וגם לעדכן גרסה.

## בנייה אוטומטית (GitHub Actions)
- בכל דחיפה לשינויים בתיקיית האפליקציה ← בנייה ב-GitHub (שם יש Android SDK מותקן).
- התוצר: `tv-movies-<גרסה>.apk` להורדה מ-Actions ← Artifacts.
- **גרסאות רשמיות:** תגית `tv-v1.0.0` ← GitHub Release עם ה-APK ועם ZIP של השרת למחשב.
- **חתימה:** מפתח חתימה קבוע שנשמר ב-GitHub Secrets. חשוב: בלי מפתח קבוע, כל עדכון ידרוש הסרה והתקנה מחדש.
- מספר גרסה עולה אוטומטית (`versionCode` = מספר הריצה).

## בנייה ידנית (חלופה)
Android Studio ← פתיחת תיקיית `android` ← Run, עם הטלוויזיה מחוברת ב-adb.

## התקנה בטלוויזיה — שלוש דרכים (המדריך יפרט את כולן)
1. **Downloader** (הכי פשוט):
   - מתקינים את Downloader מ-Google Play בטלוויזיה.
   - מאשרים "התקנה ממקורות לא ידועים" עבור Downloader (הגדרות ← אבטחה / אפליקציות).
   - מקלידים קישור ישיר ל-APK (מה-Release).
2. **Send Files to TV:** מתקינים בטלפון ובטלוויזיה, שולחים את הקובץ מהטלפון.
3. **adb מהמחשב:**
   - בטלוויזיה: הגדרות ← אודות ← לחיצה 7 פעמים על "Build" ← אפשרויות מפתח ← ניפוי באגים ברשת.
   - במחשב: `adb connect <IP של הטלוויזיה>` ואז `adb install -r tv-movies.apk`.

## רעיון: הגשת ה-APK מהשרת
השרת במחשב יחזיק עותק של ה-APK ויציג בדף הסטטוס כתובת קצרה (למשל `http://192.168.1.10:8765/app`).
מקלידים אותה ב-Downloader ← התקנה בלי GitHub. נבחר אם להכניס לשלב 5.

## עדכונים
- באפליקציה: בדיקה מול השרת אם יש גרסה חדשה יותר ← הודעה "יש עדכון" + הוראות.
- התקנה של גרסה חדשה מעל הקיימת (אותה חתימה) ← הנתונים נשמרים (ממילא רובם בשרת).

## קריטריוני סיום

- [ ] התקנה בשיטה 1 עובדת לפי המדריך על Android TV / Google TV אמיתי.
- [ ] עדכון גרסה מעל גרסה קיימת עובד בלי הסרה.
