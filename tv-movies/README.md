# הסרטים שלי — אפליקציית סרטים ל-Android TV

שני חלקים:

1. **שרת במחשב** (`server/`) — משדר את הסרטים מתיקיות במחשב לטלוויזיה ברשת הביתית, ושומר מה ראית ואיפה עצרת.
2. **אפליקציה לטלוויזיה** (`android/`) — מציגה את הסרטים עם פוסטרים, מנגנת אותם, ומסמנת מה נצפה.

## למה שרת במחשב ולא Google Drive?

- סטרימינג מ-Drive דורש התחברות לגוגל מתוך הטלוויזיה (OAuth), יש מגבלות הורדה, וקבצים גדולים נתקעים.
- שרת ברשת הביתית מהיר יותר (בלי אינטרנט בכלל), תומך בקפיצה בתוך הסרט ובכתוביות.
- **אפשר בכל זאת להשתמש ב-Drive:** מתקינים במחשב את [Google Drive for Desktop](https://www.google.com/drive/download/),
  והתיקייה של Drive מופיעה ככונן (למשל `G:\My Drive\Movies`). מוסיפים אותה ל-`config.json` — והשרת משדר גם ממנה.

## שלב 1 — הפעלת השרת במחשב (Windows)

1. התקן [Node.js](https://nodejs.org) (גרסת LTS).
2. העתק את התיקייה `tv-movies/server` למחשב.
3. העתק את `config.example.json` ל-`config.json` וערוך את רשימת התיקיות:
   ```json
   {
     "folders": ["D:\\Movies", "G:\\My Drive\\Movies"],
     "port": 8765,
     "name": "המחשב בסלון"
   }
   ```
4. לחיצה כפולה על `start-server.bat`.
   בפעם הראשונה Windows ישאל על חומת האש — אשר **רשתות פרטיות** (Private networks).
5. החלון מציג את כתובת המחשב, למשל `192.168.1.10:8765`. אפשר לבדוק בדפדפן: `http://localhost:8765`.

אפשר גם בלי config: `node server.js "D:\Movies" "E:\Series"`.

### טיפים לתיקיית הסרטים
- שם הקובץ הופך לשם הסרט: `The.Matrix.1999.1080p.BluRay.mkv` ← **The Matrix (1999)**.
- **כתוביות:** קובץ `.srt` עם אותו שם כמו הסרט (למשל `The.Matrix.1999.heb.srt`). קידוד עברית ישן (Windows-1255) מומר אוטומטית.
- **פוסטר:** תמונה עם אותו שם (`The.Matrix.1999.jpg`), או `poster.jpg` בתיקייה של הסרט.
  אם אין, ו-[ffmpeg](https://www.gyan.dev/ffmpeg/builds/) מותקן במחשב — השרת יוצר תמונה מתוך הסרט.
- תיקיות משנה מוצגות כקטגוריה (למשל `Action`).

## שלב 2 — התקנת האפליקציה בטלוויזיה

**הורדת ה-APK:** ב-GitHub ← Actions ← "TV Movies APK" ← הריצה האחרונה ← Artifacts ← `tv-movies-apk`.
(או לבנות בעצמך: לפתוח את `tv-movies/android` ב-Android Studio ← Run.)

**התקנה על הטלוויזיה** (אחת מהדרכים):
- **Send Files to TV** / **Downloader**: מתקינים את האפליקציה מחנות Google Play בטלוויזיה, שולחים אליה את ה-APK ומתקינים.
  יש לאשר "התקנה ממקורות לא ידועים" עבור האפליקציה שמתקינה.
- **adb** (מהמחשב): בטלוויזיה מפעילים אפשרויות מפתח ← ניפוי באגים ברשת, ואז:
  ```
  adb connect 192.168.1.20
  adb install app-release.apk
  ```

## שימוש

- בפתיחה הראשונה האפליקציה מחפשת את המחשב ברשת אוטומטית. אם לא נמצא — מקלידים את הכתובת שמוצגת בחלון השרת.
- **לחיצה על סרט** — מסך פרטים: נגן / המשך מאיפה שעצרת / מההתחלה / סמן כנצפה.
- **לחיצה ארוכה על סרט** — סימון מהיר כנצפה / לא נצפה.
- סינון: הכל · המשך צפייה · לא נצפו · נצפו · נוספו לאחרונה.
- בזמן צפייה: ימינה/שמאלה = קפיצה 30/10 שניות, OK = עצירה/המשך, Back = יציאה (המיקום נשמר).
- סרט שנצפה עד הסוף (מעל 92%) מסומן אוטומטית כנצפה.
- הסטטוס נשמר **במחשב** (`server/data/state.json`), כך שהוא לא הולך לאיבוד אם מתקינים מחדש את האפליקציה.

## מגבלות ידועות

- הטלוויזיה מנגנת את הקובץ כמו שהוא (בלי המרה). MP4/MKV עם H.264/H.265 ו-AAC עובדים כמעט תמיד.
  קבצי AVI ישנים, או סאונד DTS בטלוויזיות שלא תומכות בו, עלולים לא להתנגן — אז כדאי להמיר את הקובץ ל-MP4.
- השרת פתוח לכל מי שמחובר לרשת הביתית — לא לחשוף אותו לאינטרנט.
