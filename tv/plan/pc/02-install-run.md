# P2 — התקנה והפעלה של השרת ב-Windows

[← חזרה לתוכנית](../../plan.md)

## מטרה
שהשרת יותקן בקלות, יעלה לבד עם הדלקת המחשב, ויהיה נגיש לטלוויזיה — בלי ידע טכני.

## דרישות
- Windows 10 / 11.
- **Node.js LTS** — התקנה מ-nodejs.org (המתקין הרגיל, "Next" עד הסוף).
- **ffmpeg** — לא חובה. משמש רק ליצירת תמונה מתוך הסרט כשאין פוסטר, ולזיהוי רזולוציה וקודקים.
- טלוויזיה ומחשב **באותה רשת ביתית**.

## התקנה (תוצר מתוכנן)
תיקייה אחת להורדה (ZIP), למשל `C:\TvMovies\`:
```
TvMovies\
  server\                 קוד השרת
  config.json             נוצר בהפעלה הראשונה
  start-server.bat        הפעלה רגילה (עם חלון)
  install-autostart.bat   הפעלה אוטומטית עם Windows
  remove-autostart.bat    ביטול
  README-he.md            מדריך
```

### הפעלה ראשונה — אשף קצר בחלון
1. בדיקה ש-Node.js מותקן; אם לא — הודעה עם קישור.
2. שאלות: שם המחשב, תיקיית סרטים, תיקיית סדרות, מפתח TMDB (אפשר לדלג).
3. שמירה ל-`config.json`.
4. הצגת הכתובת לחיבור מהטלוויזיה.

אפשר תמיד לערוך את `config.json` ידנית (עם הסבר בקובץ עצמו).

## חומת האש של Windows
- בהפעלה הראשונה Windows שואל אם לאפשר ל-Node.js גישה לרשת ← לסמן **רשתות פרטיות** ולאשר.
- אם פספסו: `install-autostart.bat` (שרץ כמנהל) יוסיף כללים:
  - TCP 8765 (שידור), UDP 8766 (גילוי) — לרשתות פרטיות בלבד.
- **חשוב:** הרשת הביתית צריכה להיות מוגדרת ב-Windows כ"פרטית" ולא "ציבורית". המדריך יסביר איך לבדוק.

## הפעלה אוטומטית
`install-autostart.bat` יוצר משימה ב-Task Scheduler:
- מופעלת בכניסה למשתמש (או בעליית המחשב).
- רצה ברקע **בלי חלון**.
- מופעלת מחדש אוטומטית אם השרת נפל (עד 3 פעמים).
- הלוג נכתב ל-`data\server.log`.

חלופה שנבחן: הרצה כ-Windows Service (דרך NSSM). יותר יציב, אבל מסובך יותר להתקנה — כנראה לא בשלב הראשון.

## שינה וחיסכון בחשמל
- מחשב במצב שינה ← הטלוויזיה לא יכולה להתחבר.
- המדריך יסביר: הגדרות ← מערכת ← צריכת חשמל ← "שינה: אף פעם" כשמחובר לחשמל, או השארת המחשב דולק בזמן צפייה.
- **בזמן שידור** השרת יבקש מ-Windows לא להירדם (כמו נגן וידאו), ומשחרר כשהשידור נגמר.
- רעיון לעתיד: Wake-on-LAN מהאפליקציה.

## כתובת IP קבועה (מומלץ)
- הגילוי האוטומטי מטפל בשינוי כתובת, אבל כתובת קבועה מונעת בעיות.
- המדריך יסביר איך להגדיר "DHCP Reservation" בראוטר (כללי, כי כל ראוטר שונה).

## עדכון גרסה
- מחליפים את תיקיית `server\` בגרסה החדשה. `config.json` ו-`data\` נשמרים.
- דף הסטטוס מציג את מספר הגרסה.

## פתרון בעיות (יופיע במדריך)
| בעיה | בדיקה |
|---|---|
| הטלוויזיה לא מוצאת את המחשב | השרת רץ? רשת "פרטית"? חומת אש? אותה רשת? לנסות להקליד כתובת ידנית |
| אין פוסטרים | מפתח TMDB? יש אינטרנט במחשב? דף הסטטוס |
| סרט לא מופיע | התיקייה ב-`config.json`? סיומת נתמכת? "רענן" |
| הסרט נתקע | Wi-Fi חלש? לנסות כבל רשת; לבדוק את גודל הקובץ (4K = הרבה) |

## קריטריוני סיום

- [ ] אחרי הפעלה מחדש של המחשב, השרת עולה לבד.
- [ ] הטלוויזיה מוצאת את המחשב בלי הגדרות נוספות (אחרי אישור חומת האש).
