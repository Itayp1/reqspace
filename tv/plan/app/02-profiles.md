# A2 — מסך בחירת פרופיל

[← חזרה לתוכנית](../../plan.md)

## מטרה
"מי צופה?" — בחירת פרופיל בכניסה, כך שכל אחד רואה את ההיסטוריה וה"המשך צפייה" שלו.

## המסך
```
                 מי צופה?

   ( 🦁 )      ( 🐱 )      ( 🚀 )      (  +  )
    איתי        נועה        ילדים      הוסף פרופיל

                                  [ ניהול פרופילים ]
```
- עיגולים גדולים בצבע הפרופיל עם אייקון.
- הפוקוס מתחיל על **הפרופיל האחרון שנבחר**.
- יש רק פרופיל אחד ← מדלגים על המסך (אפשר להחליף מההגדרות).

## התנהגות
- בחירה ← מסך הבית של הפרופיל.
- **"האם לזכור?"** — הגדרה: "שאל בכל פתיחה" (ברירת מחדל) / "פתח תמיד את הפרופיל האחרון".
- החלפת פרופיל מתוך האפליקציה: אייקון הפרופיל בפינת מסך הבית.

## הוספה ועריכה
- **שם:** הקלדה במקלדת של הטלוויזיה (או הכתבה קולית).
- **צבע:** 8 צבעים קבועים.
- **אייקון:** 12 אייקונים קבועים (חיות / אובייקטים), מצוירים באפליקציה — בלי תמונות מהאינטרנט.
- **מחיקה:** אישור כפול ("כל היסטוריית הצפייה של X תימחק").
- נשמר בשרת ([S4](../server/04-profiles-state.md)) ← אותם פרופילים בכל טלוויזיה בבית.

## קריטריוני סיום
- [ ] יצירה, עריכה, מחיקה ובחירה עם השלט בלבד.
- [ ] פרופיל שנבחר נשלח בכל הבקשות הרלוונטיות.
- [ ] מעבר פרופיל מרענן את מסך הבית.
