# S3 — מטא-דאטה אוטומטי מ-TMDB

[← חזרה לתוכנית](../../plan.md)

## מטרה
לכל סרט וסדרה: פוסטר, תמונת רקע, תקציר (בעברית כשיש), שנה, ז'אנרים, דירוג ואורך. לפרקים: שם הפרק ותקציר.

## למה TMDB
- חינמי לשימוש אישי, עם מפתח API.
- יש תרגומים לעברית להרבה סרטים וסדרות.
- תמונות באיכות טובה.

## הכנה (חד-פעמי, על ידי המשתמש)
1. נרשמים ב-themoviedb.org.
2. Settings ← API ← מבקשים מפתח (Developer, שימוש אישי).
3. מדביקים את המפתח ב-`config.json` בשדה `tmdbApiKey`.
4. **בלי מפתח השרת ממשיך לעבוד** — עם שמות מהקבצים ותמונה מתוך הסרט (אם ffmpeg מותקן) או פוסטר גנרי.

## תהליך הזיהוי
1. **ניקוי שם הקובץ/תיקייה:** `The.Matrix.1999.1080p.BluRay.x264` ← שם `The Matrix`, שנה `1999`.
   מסירים תגיות נפוצות: רזולוציה, מקור, קודק, קבוצת שחרור.
2. **חיפוש ב-TMDB:** `search/movie` או `search/tv` עם השם והשנה.
3. **בחירת התוצאה:** התאמת שנה מדויקת קודמת; אחר כך הפופולרית ביותר.
4. **פרטים מלאים:** בקשה בעברית (`language=he-IL`); שדות חסרים (למשל תקציר) ← בקשה נוספת באנגלית.
5. **סדרות:** בנוסף, פרטי כל עונה (שמות ותקצירי פרקים).

## תיקון ידני כשהזיהוי שגוי
- **מזהה בשם התיקייה:** `The Office (2005) [tmdbid-2316]` ← משתמשים ישירות במזהה.
- **קובץ `override.json`** ב-`data\`: מיפוי מזהה פריט ← מזהה TMDB.
- בדף הסטטוס: רשימת "לא זוהו" + "זוהה בביטחון נמוך" עם קישור ל-TMDB לבדיקה.

## תמונות
- מורידים פוסטר (רוחב 500) ותמונת רקע (רוחב 1280) לתיקיית `data\images\`.
- **עדיפות:** תמונה מקומית ליד הקובץ (`poster.jpg` או `<שם הקובץ>.jpg`) ← TMDB ← פריים מתוך הסרט (ffmpeg) ← פוסטר גנרי עם השם.
- השרת מגיש את התמונות בעצמו (`/images/{id}/poster`) — הטלוויזיה לא פונה לאינטרנט.
- כותרת `Cache-Control` ארוכה; האפליקציה שומרת מטמון.

## מטמון ועדכון
- כל התוצאות נשמרות ב-`data\metadata.json` לפי מזהה פריט.
- לא מורידים שוב פריט שכבר זוהה.
- פריט שלא זוהה ← ניסיון חוזר פעם ביום.
- סדרות פעילות ← רענון פרטי עונות פעם בשבוע (לשמות פרקים חדשים).
- כפתור בדף הסטטוס: "רענן מטא-דאטה לכל הספרייה".

## הגבלות קצב ושגיאות
- תור עם עד 4 בקשות במקביל (TMDB מגביל בערך 40 בקשות לשנייה).
- אין אינטרנט / מפתח שגוי ← הודעה בלוג ובדף הסטטוס, הספרייה ממשיכה לעבוד.
- הורדת מטא-דאטה רצה ברקע ולא מעכבת את עליית השרת.

## קרדיט
תנאי השימוש של TMDB דורשים קרדיט — שורה במסך "אודות" באפליקציה ובדף הסטטוס.

## קריטריוני סיום
- [ ] 20 סרטים ו-5 סדרות לדוגמה מזוהים נכון (כולל שמות עם שנה, בלי שנה, ועם תגיות).
- [ ] תקציר בעברית כשקיים, אנגלית כשלא.
- [ ] עובד גם בלי מפתח (מצב מוגבל).
- [ ] תיקון ידני דרך `[tmdbid-…]` עובד.
- [ ] הפעלה שנייה לא שולחת בקשות ל-TMDB לפריטים קיימים.
