# S2 — זיהוי סדרות, עונות ופרקים

[← חזרה לתוכנית](../../plan.md)

## מטרה
להפוך ערימת קבצים בתיקיית הסדרות למבנה מסודר: סדרה ← עונות ← פרקים, ולדעת מהו "הפרק הבא" לכל פרופיל.

## מבנה תיקיות צפוי
```
D:\Series\
  Friends\
    Season 1\
      Friends.S01E01.The.One.Where.It.All.Began.mkv
      Friends.S01E01.heb.srt
    Season 2\
      ...
  Breaking Bad (2008)\
    S01E01.mkv            ← גם בלי תיקיית עונה
```
המבנה המדויק מתועד למשתמש ב-[P1](../pc/01-folders.md).

## כללי זיהוי
1. **שם הסדרה** = שם התיקייה הראשונה מתחת לתיקיית `series` (למשל `Friends`). שנה בסוגריים נשמרת בנפרד (`Breaking Bad (2008)` ← שם + 2008).
2. **עונה ופרק** — לפי שם הקובץ, לפי סדר העדיפות:
   - `S01E02`, `s1e2` (הנפוץ ביותר)
   - `1x02`
   - `Season 1\Episode 2` / `E02` כשהעונה ידועה מהתיקייה
   - פרק כפול: `S01E01E02` / `S01E01-E02` ← פרק אחד שמכסה שניים
3. **עונה 0 / Specials** — תיקייה בשם `Specials` או `S00`.
4. **קבצים שלא זוהו** — מוצגים תחת "פרקים נוספים" של הסדרה, ממוינים לפי שם, ומופיעים ברשימת "בעייתיים" בדף הסטטוס.
5. **מיון:** עונות לפי מספר; פרקים לפי מספר.

## "הפרק הבא" (Next Up)
מחושב לכל פרופיל:
1. אם יש פרק באמצע צפייה — הוא "המשך צפייה".
2. אחרת: הפרק שאחרי הפרק **האחרון שנצפה** (לפי סדר עונה/פרק, לא לפי זמן).
3. בסוף עונה ← הפרק הראשון של העונה הבאה.
4. אם כל הפרקים נצפו — הסדרה לא מופיעה ב"הפרק הבא".
5. סדרה מופיעה בשורה רק אם הפרופיל צפה בה ב-60 הימים האחרונים (כדי לא להציף).

## סימון עונה / סדרה כנצפתה
- "סמן עונה כנצפתה" ← כל הפרקים בעונה.
- "סמן סדרה כנצפתה" ← כל הפרקים.
- "סמן עד כאן" ← כל הפרקים עד הפרק הנבחר (שימושי כשמתחילים באמצע).

## פרקים חדשים
- פרק שנוסף אחרי שהסדרה כבר נצפתה כולה ← הסדרה חוזרת ל"הפרק הבא" עם הפרק החדש.
- בשורה "נוספו לאחרונה" — הסדרה מופיעה פעם אחת עם תווית "פרק חדש".

## קריטריוני סיום
- [ ] כל דוגמאות השמות בקובץ הזה מזוהות נכון (בדיקות יחידה).
- [ ] פרק כפול מזוהה כפרק אחד.
- [ ] "הפרק הבא" נכון במעבר בין עונות ואחרי צפייה בפרקים לא לפי הסדר.
- [ ] קבצים שלא זוהו מופיעים ולא נעלמים.
