# תוכנית: "הסרטים שלי" — סרטים וסדרות על Android TV

מסמך זה הוא התוכנית הראשית. כל משימה מפורטת בקובץ נפרד (קישורים בטבלאות למטה).
**בשלב זה רק מתכננים — לא מפתחים.**

> הערה: בענף כבר קיימת טיוטת קוד ראשונית (`server/`, `android/`) שנכתבה לפני שהוחלט לתכנן קודם.
> היא תשמש לכל היותר כנקודת התחלה, ותעודכן לפי התוכנית הזו כשנתחיל לפתח.

---

## 1. המטרה

לצפות בטלוויזיה (Android TV) בסרטים ובסדרות שנמצאים בתיקיות במחשב הביתי, בחוויה שדומה לנטפליקס:
פוסטרים ותקצירים, "המשך צפייה", "הפרק הבא", כתוביות בעברית, חיפוש, וכמה פרופילים — לכל אחד רשימה משלו של מה ראה.

## 2. החלטות שנסגרו

| נושא | החלטה |
|---|---|
| מקור הסרטים | **רק תיקיות במחשב** (לא Google Drive) |
| תוכן | **סרטים וסדרות** (עונות ופרקים) |
| מחשב | **Windows** |
| פוסטרים ותקציר | **אוטומטי מ-TMDB** (דורש מפתח API חינמי) |
| כתוביות | **עברית**, קבצי `.srt` / `.vtt` ליד הקובץ |
| פרופילים | **כן** — סטטוס צפייה נפרד לכל פרופיל |
| חיפוש | **כן** |
| איפה נשמר הסטטוס | **במחשב** (לא בטלוויזיה) — לא הולך לאיבוד בהתקנה מחדש |

## 3. ארכיטקטורה

```
┌──────────────────────── מחשב Windows ────────────────────────┐

│   │  שרת "הסרטים שלי"         │◄────►│ TMDB (אינטרנט) │         │
│   │  • סריקת ספרייה           │      └───────────────┘         │
│   │  • שידור וידאו            │                                │

│   │  • מטא-דאטה ופוסטרים      │    images\ (מטמון)             │
│   └────────────┬─────────────┘                                │
└────────────────┼──────────────────────────────────────────────┘
                 │  רשת ביתית (Wi-Fi / כבל) — HTTP + UDP לגילוי
┌────────────────┼──────── Android TV ──────────────────────────┐
│   ┌────────────▼─────────────┐                                │
│   │ אפליקציית "הסרטים שלי"    │                                │
│   │ פרופיל ← בית ← סרט/סדרה   │                                │

│   └──────────────────────────┘                                │
└───────────────────────────────────────────────────────────────┘
```

**טכנולוגיות:**
- **שרת:** Node.js (LTS), בלי תלות בספריות חיצוניות ככל האפשר — קל להתקנה ב-Windows.
- **אפליקציה:** Kotlin, Jetpack Compose for TV, נגן Media3 (ExoPlayer), Coil לתמונות.
- **בנייה:** GitHub Actions בונה את ה-APK; הורדה והתקנה ידנית בטלוויזיה.

## 5. סדר העבודה (שלבים)

כל שלב מסתיים במשהו שאפשר לבדוק בפועל.

| שלב | משימות | מה מקבלים בסוף השלב |
|---|---|---|
| **1. שרת בסיסי** | S1, S4, S5 (חלקי), P1, P2 | השרת רץ במחשב, רואים את רשימת הסרטים בדפדפן, אפשר לנגן קובץ מהדפדפן |
| **2. סדרות ומטא-דאטה** | S2, S3, S5 (מלא) | בדפדפן רואים סרטים וסדרות עם פוסטרים ותקצירים |
| **3. אפליקציה — צפייה בסרטים** | A1, A2, A3, A6, R1, P3 (הגדרות נגן + מדריך רשת) | מתקינים בטלוויזיה, בוחרים פרופיל, צופים בסרט, "המשך צפייה" עובד |
| **4. אפליקציה — סדרות וחיפוש** | A4, A5 | גרסה מלאה: סדרות, פרק הבא אוטומטי, חיפוש |
| **5. ליטוש ובדיקות** | R2, P2 (הפעלה אוטומטית), P3 (מסך מידע, בדיקת מהירות, כלי המרה) | בדיקה מלאה בבית, מדריך התקנה בעברית |

**תלויות עיקריות:**
- S5 (החוזה של ה-API) נקבע לפני שמתחילים את האפליקציה — כך שני החלקים מתפתחים בלי להתנגש.
- A3–A6 תלויים ב-A1 וב-A2.
- S3 תלוי ב-S2 (צריך לדעת מה סדרה ומה סרט לפני שמחפשים ב-TMDB).

## 6. מה **לא** בתוכנית (כרגע)

- Google Drive ישירות מהטלוויזיה.
- המרת וידאו בזמן אמת (transcoding) — הטלוויזיה מנגנת את הקובץ המקורי. ראו [plan/app/06-player.md](plan/app/06-player.md#פורמטים).
- צפייה מחוץ לבית (דרך האינטרנט).
- הורדת כתוביות אוטומטית מהאינטרנט.
- אפליקציה לטלפון.

אפשר להוסיף כל אחד מאלה כשלב עתידי.

## 7. סיכונים ונקודות פתוחות

| סיכון | השפעה | מה עושים |
|---|---|---|
| קובץ בפורמט שהטלוויזיה לא תומכת בו (AVI ישן, סאונד DTS) | הסרט לא מתנגן | הודעה ברורה באפליקציה; בשרת — סימון קבצים "בעייתיים"; המרה ידנית ל-MP4 |
| Wi-Fi חלש לקבצי 4K | עצירות בניגון | כבל רשת, 5GHz, באפר גדול, בדיקת מהירות ומסך מידע — ראו [P3](plan/pc/03-smooth-playback.md) |
| חומת האש של Windows חוסמת | הטלוויזיה לא מוצאת את המחשב | הסבר מסודר ב-P2 + אפשרות הקלדת כתובת ידנית |
| TMDB מזהה סרט לא נכון | פוסטר ותקציר שגויים | זיהוי לפי שם + שנה; אפשרות תיקון ידני (קובץ `.nfo` או מזהה TMDB בשם התיקייה) |
| המחשב כבוי / נרדם | אין גישה לסרטים | הגדרת שינה ב-Windows (P2); הודעה ברורה באפליקציה |
| כתובת IP של המחשב משתנה | צריך להתחבר מחדש | גילוי אוטומטי בכל פתיחה; המלצה ל-IP קבוע בראוטר |
