# Consolidation plan: tests/e2e/platform/ and tests/e2e/legacy-manual/

Scope: 19 spec files in `platform/` (100 tests: 38 static, 62 generated by the `api-authorization` loops) and 8 spec files in `legacy-manual/` (198 tests). Read-only analysis. No test was run. Line numbers are `file:line` in the current tree.

Login legend: **UI** = `registerUser`/`loginUi` in the browser; **API** = `apiAs`/`apiAsAdmin`/a `request` context; **NEW** = fresh user per test; **ANON** = no login; **STATIC** = reads source files, no browser.

Note: `docs/plans/consolidation-admin.md` describes the admin folder as 25 files. The admin world is now 5 specs (`admin-errors`, `admin-settings`, `admin-users`, `admin-workspaces-and-logs`, `system-backup`). Admin references below use these names.

## 0. Findings that change the plan

1. **No `test.fail()` exists in legacy-manual.** The headers of 7 of the 8 files, and `manual-pass-bugs`, say a still-broken bug is marked `test.fail()`. `grep -n "\.fail(\|fixme"` over both folders matches only comments. The docs they cite (`MANUAL_TEST_PLAN_FAILED.md`, `BUGS-MANUAL-PASS.md`) are not in the repo (`find . -iname "MANUAL_TEST_PLAN*" -o -iname "BUGS-MANUAL*"` returns nothing). Every legacy test is a plain assertion, so any test whose bug still exists is red. Do not assume the folder is green. Run each moved test after the move.
2. **Two platform files cannot be merged into anything.** `extension.spec.ts` runs only in the `extension` project and `electron-app.spec.ts` is excluded from `sqlite`/`postgres`/`mysql` (`playwright.config.ts` l.92, 99, 106 `testIgnore`; l.111-116 `electron` project; l.120-122 `extension` project). Moving their tests into another file changes which project runs them.
3. **Hardcoded ports** (CLAUDE.md: never hardcode ports): `platform/extension.spec.ts:72` uses `http://localhost:3005/api/auth/me`; `platform/api-authorization.spec.ts:27` falls back to `localhost:3005`; `legacy-manual/manual-failed-jklm.spec.ts:46` and `manual-failed-efgi.spec.ts:34` rewrite the Origin to `localhost:5173`. Use `API_URL` and `CLIENT_PORT`.
4. **13 HIGH duplicates** (section 4), to be deleted by the rule. **0 deprecated tests** (section 3).
